# HEADLESS-PUMPKIN-GUY
2D Endless Platformer Game, where the headless pumpkin guy is trying to light his pumpkin head.
Team (Spooky Month): Esther, Anish, Erik, Jayden, Cale 
[] Jumping - Yes
[] Item Collection - Yes
[] Collision and physics - Yes
[] Moving sprites and input - Yes
[] Timing - Yes
[] Invisible walls - Yes
[] Audio - Yes
[] UI(Menus, HUD) - Yes


•	Item collection – collecting the light we need too light up the pumpkin head
•	Collision and physics – Platforms we must jump on to get our collectibles
•	Moving sprites and input – The player, The obstacles
•	Jumping- jumping to get to our pumpkin
•	Timing- after we collect each light, we must get to the pumpkin head before the light goes out, which works with how much time we have.
•	Invisible walls – The wall at the start so the player can’t go backwards.
•	Audio- spooky music at the start, when the player collects the light, when the player jumps, when the player is hit by obstacles, when the player wins and fails.
•	UI(Menus)- start menu, pause menu, game over menu, win menu
•	UI(HUD)- health, items collected, timer (pumpkin head at the top that dims)
